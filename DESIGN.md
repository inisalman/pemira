# Arahan desain PEMIRA

Versi 1.0 · 14 September 2026

Sumber arahan: pemilik proyek. Dokumen ini mencatat pilihan visual yang diberikan pengguna; belum ada implementasi antarmuka.

| Elemen | Arahan |
| --- | --- |
| Gaya | Modern light |
| Warna hijau utama | `#2A6B5C` |
| Warna putih hangat | `#FFF9F2` |
| Font | Inter |

Arahan berlaku untuk halaman publik, login, dashboard pemilih, surat suara, quick count, dan halaman admin. Tema gelap tidak termasuk permintaan saat ini.

Detail komponen, ukuran, jarak, status interaksi, dan tampilan ponsel akan diterapkan serta diperiksa pada fase antarmuka. Kebutuhan keyboard, pembaca layar, dan indikator status mengikuti NFR-05 di [PRD](docs/PRD.md). Warna status tambahan, jika diperlukan, harus membantu menjelaskan keadaan seperti gagal atau berhasil tanpa mengganti palet utama.

Urutan pelaksanaan terdapat di [rencana implementasi](docs/IMPLEMENTATION_PLAN.md), dengan checklist di [TASKLIST](docs/TASKLIST.md).
